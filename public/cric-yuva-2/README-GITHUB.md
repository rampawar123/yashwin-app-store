# CRIC YUVA 2

New standalone Cric Yuva cricket scoring project based on the existing Cric Yuva UI and match/scoring flow.

## Branding
- App name: CRIC YUVA 2
- Logo: `cric-yuva-2-logo.png`
- Original visual direction is retained.

## Main flow
Home → Start Match → Team A / Team B → Playing XI → Toss → Opening setup → Live Scoring → Innings transition → Result / Super Over → Full Scorecard.

## Player display
Team list shows only player photo + name. Full player details open on the player profile.

## GitHub upload
This folder is intended to be uploaded as a separate repository named `cric-yuva-2`.

Do not commit production secrets, `.env` files, database files, or generated `node_modules`.

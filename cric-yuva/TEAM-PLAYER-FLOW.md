# CRIC YUVA Team → Player Flow

## New/clarified flow

1. Open **My Team**.
2. Use **CREATE TEAM** to create Team A, Team B, Team C, etc.
3. Select a team from **MY TEAMS**.
4. In **SQUAD PLAYERS**, tap **Add Player**.
5. Enter player name, role, jersey number and optional photo.
6. Use **SAVE & ADD ANOTHER** to add multiple players quickly.
7. Players are saved inside the currently selected team only.
8. Open **Start Match** and select the saved teams.
9. Step 2 / Playing XI automatically loads the saved roster for each team.
10. If a roster is empty, the screen now shows **OPEN TEAM & ADD PLAYERS** instead of an unexplained empty list.

## Start Match shortcuts

Step 1 now has **TEAM A PLAYERS** and **TEAM B PLAYERS** buttons. They open the selected team's My Team page. If a custom team name was typed instead of selecting a saved team, the shortcut first saves that name as a normal team so players can be stored and reused.

The database Player ID remains an internal key only; the user does not need to enter or manage it.
